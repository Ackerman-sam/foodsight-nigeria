# FoodSight Nigeria — Dashboard

Phase 5 / Objective 4 deliverable: a Streamlit dashboard with three views (Forecast, Driver,
Alert) for the nine core NBS food commodities.

## Running locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Opens at `http://localhost:8501`. No API keys or external services required — everything
reads from static CSVs in `data/`.

## Deploying to Streamlit Cloud

1. Push this folder (`app.py`, `requirements.txt`, `data/`) to a GitHub repo.
2. On [share.streamlit.io](https://share.streamlit.io), point a new app at the repo, main
   file `app.py`.
3. No secrets or environment variables needed.

## Data files (in `data/`) and where each comes from

| File | Generated by | Regenerate when |
|---|---|---|
| `FoodSight_national_merged.csv` | `FoodSight_Phase2_National_Merge.ipynb` | Any Phase 1/2 cleaning change |
| `future_forecasts_6mo.csv` | ARIMA re-fit on full series (see below) | Monthly, as new data arrives |
| `all_commodities_mape_summary.csv` | `FoodSight_Phase3_All_Commodities.ipynb` | Any model/feature change |
| `all_commodities_shap_pct.csv` | `FoodSight_Phase3_All_Commodities.ipynb` | Any model/feature change |
| `alert_thresholds.csv` | Rolling 24-month + pre-subsidy percentiles (see below) | Monthly, as new data arrives |
| `structural_break_summary.csv` | `FoodSight_EDA_Correlation_StructuralBreaks.ipynb` | Rarely (break dates are fixed) |

**`future_forecasts_6mo.csv`** is not a byproduct of the Phase 3 notebook — it's a separate
step: each commodity's `auto_arima`-selected order is re-fit on the *entire* available
series (not just the walk-forward training window), then forecast 6 months ahead with an
80% confidence interval. Re-run this whenever new monthly data is added, ideally as part of
a monthly refresh job alongside re-merging Phase 2.

**`alert_thresholds.csv`** combines two thresholds: the original pre-subsidy-removal (before
April 2023) 75th/90th percentiles from the proposal's design, and a rolling 24-month 75th/90th
percentile ending the month before the latest observation. The dashboard's traffic light uses
the rolling thresholds — using the pre-2023 baseline would flag every commodity red
permanently, since prices have risen structurally since the subsidy removal. The static
pre-subsidy values are retained and displayed for historical reference.

## Design notes / known limitations

- **Forecast horizon**: 6 months ahead, ARIMA only (the model that won every commodity under
  walk-forward validation in Phase 3). ARIMAX/LightGBM forecasts are not shown in the
  Forecast View for this reason, though their walk-forward accuracy is shown in the
  "Model comparison" expander for transparency.
- **Driver View** uses LightGBM's SHAP values even though ARIMA is more accurate — LightGBM
  is the only one of the three models with engineered features to attribute; this is
  explained in-app via the "How to read this" expander so it isn't presented as the
  forecast's actual mechanism.
- **National level only.** No state/zone breakdown, consistent with the project's documented
  scope decision.
- **Usability evaluation** (getting real non-technical users to test this) has not been
  conducted.
